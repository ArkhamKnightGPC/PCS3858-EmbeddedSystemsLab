# PCS 3858: Embedded Systems Laboratory

This repository contains the group project for the course [**PCS 3838: Artificial Intelligence**](https://uspdigital.usp.br/jupiterweb/obterDisciplina?sgldis=PCS3858&verdis=1) at the University of São Paulo.

## Wire color code

| Signal    | Color     |
| --------  | -------   |
| 3.3V      | red       |
| GND       | black     |
| SCL       | yellow    |
| SDA       | blue      |
